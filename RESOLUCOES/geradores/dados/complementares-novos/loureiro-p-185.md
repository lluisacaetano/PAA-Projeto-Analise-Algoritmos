Resposta. O número máximo de regiões determinado por n retas no plano satisfaz a recorrência L_0 = 1 e L_n = L_{n−1} + n para n ≥ 1, e portanto tem a forma fechada L_n = n(n+1)/2 + 1 para todo n ≥ 0 (L_0..L_5 = 1, 2, 4, 7, 11, 16). A recorrência vale porque a n-ésima reta acrescenta no máximo n regiões a qualquer configuração de n − 1 retas, e acrescenta exatamente n quando as retas estão em posição geral (nenhum par paralelo, nenhum trio passando por um mesmo ponto), configuração que existe para todo n. Em particular L_n ∈ Θ(n²), com c₁ = 1/2, c₂ = 1, n₀ = 2.

CHECAGEM DE INTERPRETAÇÃO:
Leituras possíveis de "número máximo de regiões L_n determinado por n retas": (i) o máximo, sobre todas as configurações de n retas distintas no plano, do número de regiões (componentes conexas do plano menos a união das retas); (ii) o número de regiões de uma configuração específica. A palavra "máximo" e os valores do enunciado (L_2 = 4 exige duas retas concorrentes; duas paralelas dariam 3) fixam a leitura (i), que é a resolvida aqui. Seguindo a estratégia do slide 184, há três etapas: pequenos casos; achar e provar a recorrência; achar e provar a forma fechada. Se se admitissem retas repetidas, uma reta repetida não muda a união e acrescenta 0 regiões, o que não afeta o máximo; daqui em diante as retas são distintas.

ETAPA 1 — PEQUENOS CASOS:
Sem retas, o plano é uma região: L_0 = 1. Uma reta divide o plano em dois semiplanos: L_1 = 2. Duas retas: se paralelas, 3 regiões; se concorrentes, 4; logo L_2 = 4. Três retas: a terceira reta, cortando as duas primeiras (concorrentes) em dois pontos distintos, fica dividida em 3 pedaços, e cada pedaço divide uma região em duas: 4 + 3 = 7 regiões (o triângulo do meio, 3 regiões encostadas nos lados e 3 encostadas nos vértices). Se as três passam por um mesmo ponto, só 6. A sequência 1, 2, 4, 7 sugere que a n-ésima reta acrescenta n regiões: L_n = L_{n−1} + n.

ETAPA 2 — A RECORRÊNCIA. PRELIMINAR: AS REGIÕES SÃO CONVEXAS.
Seja um conjunto finito de retas r_1, …, r_m. Cada r_i separa o plano em dois semiplanos abertos. Para cada ponto p fora de todas as retas, o "vetor de lados" de p diz em qual semiplano aberto de cada r_i o ponto está. O conjunto C dos pontos com um dado vetor de lados é a interseção de m semiplanos abertos, logo é aberto e convexo (em particular conexo). Esses conjuntos (os não vazios) particionam o plano menos a união das retas, são abertos e disjuntos, e cada um é conexo; logo são exatamente as componentes conexas, isto é, as regiões. Conclusão: toda região é um aberto convexo, e dois pontos fora das retas estão na mesma região se e somente se estão do mesmo lado de cada reta. Com m = 0 há um único vetor (vazio) e uma única região, o plano.

ETAPA 2 — LEMA (QUANTO UMA RETA NOVA ACRESCENTA):
Seja uma configuração de n − 1 retas distintas (n ≥ 1) e ℓ uma reta distinta de todas elas. Seja k o número de pontos distintos em que ℓ encontra as n − 1 retas. Então a configuração com as n retas tem exatamente (regiões antigas) + (k + 1) regiões.

Prova. Cada reta antiga, sendo distinta de ℓ, encontra ℓ em no máximo um ponto; logo os pontos de ℓ que estão em alguma reta antiga são exatamente k pontos distintos, e k ≤ n − 1. Retirar k pontos distintos de uma reta deixa k + 1 pedaços (intervalos abertos: duas semirretas e k − 1 segmentos se k ≥ 1; a reta inteira se k = 0). Cada pedaço é convexo e não encontra reta antiga, então todos os seus pontos estão do mesmo lado de cada reta antiga: o pedaço inteiro está numa única região antiga.
Seja R uma região antiga com ℓ ∩ R ≠ ∅. O conjunto ℓ ∩ R é convexo, está contido em ℓ e não encontra reta antiga, então está contido num único pedaço P; como P está inteiro numa região, que encontra R, essa região é R, e P ⊂ ℓ ∩ R. Logo ℓ ∩ R = P. Assim a correspondência pedaço ↦ região que o contém é uma bijeção entre os k + 1 pedaços e as regiões antigas que ℓ encontra: são exatamente k + 1 regiões antigas cortadas por ℓ.
Pelo preliminar, as regiões novas são as regiões antigas subdivididas pelo lado de ℓ. Uma região antiga R que não encontra ℓ é convexa e não toca ℓ, então está toda de um lado de ℓ e continua sendo uma única região. Uma região antiga R que encontra ℓ, num ponto q, é aberta, então contém um pequeno disco em torno de q, que tem pontos dos dois lados de ℓ; logo R se divide em exatamente dois conjuntos não vazios, R ∩ (semiplano aberto de um lado) e R ∩ (do outro lado). Contando: regiões novas = (antigas não cortadas) + 2·(antigas cortadas) = (antigas) + (antigas cortadas) = (antigas) + (k + 1). ∎

ETAPA 2 — COTA SUPERIOR: A n-ÉSIMA RETA ACRESCENTA NO MÁXIMO n REGIÕES.
Pelo lema, como k ≤ n − 1, a n-ésima reta acrescenta k + 1 ≤ n regiões a qualquer configuração das n − 1 retas anteriores. Defina U_0 = 1 e U_n = U_{n−1} + n. Afirmação Q(n): toda configuração de n retas distintas tem no máximo U_n regiões. Base n = 0: 1 região = U_0. Passo (n ≥ 1): dada uma configuração de n retas, retire uma delas, ℓ; as n − 1 restantes têm, por Q(n − 1), no máximo U_{n−1} regiões; recolocando ℓ, o lema dá no máximo U_{n−1} + n = U_n regiões. Logo L_n ≤ U_n para todo n ≥ 0.

ETAPA 2 — n É ATINGÍVEL: POSIÇÃO GERAL.
Tome as retas r_i: y = i·x − i², para i = 1, 2, 3, … Os coeficientes angulares são distintos, então quaisquer duas são concorrentes (nenhum par paralelo e todas distintas). A interseção de r_i e r_j (i ≠ j) resolve i·x − i² = j·x − j², isto é, (i − j)x = i² − j², x = i + j; o ponto é (i + j, i·j). Ao acrescentar r_n às retas r_1, …, r_{n−1}, os pontos de encontro têm abscissas n + 1, n + 2, …, n + (n − 1), todas distintas: são exatamente k = n − 1 pontos distintos. (Isso diz também que três retas da família nunca passam por um mesmo ponto.) Pelo lema, r_n acrescenta exatamente n regiões. Seja A_n o número de regiões de r_1, …, r_n; então A_0 = 1 e A_n = A_{n−1} + n, a mesma recorrência de U, de onde A_n = U_n para todo n ≥ 0 (indução imediata: A_0 = U_0, e A_{n−1} = U_{n−1} implica A_n = U_{n−1} + n = U_n).

ETAPA 2 — CONCLUSÃO:
U_n = A_n ≤ L_n (L_n é o máximo e A_n é atingido) e L_n ≤ U_n (cota superior). Logo L_n = U_n, isto é, L_0 = 1 e L_n = L_{n−1} + n para n ≥ 1. Note que a cota "no máximo n" vale para toda configuração e a igualdade só para configurações em que a nova reta corta as anteriores em n − 1 pontos distintos; se a reta nova é paralela a alguma anterior, ou passa por um ponto onde duas anteriores já se cruzam, ela acrescenta menos que n (ex.: três retas por um ponto dão 6, não 7); e uma configuração com algum par paralelo ou algum trio concorrente tem menos que L_n regiões.

ETAPA 3 — FORMA FECHADA, POR INDUÇÃO:
Desenrolando, L_n = 1 + (1 + 2 + … + n) = 1 + n(n+1)/2, que se prova por indução.
P(n): L_n = n(n+1)/2 + 1.
Base n = 0: L_0 = 1 e 0·1/2 + 1 = 1. Confere. (Também n = 1: 1·2/2 + 1 = 2; n = 2: 2·3/2 + 1 = 4, como no enunciado.)
Hipótese de indução: para um n ≥ 1, vale P(n − 1): L_{n−1} = (n − 1)n/2 + 1.
Passo: L_n = L_{n−1} + n = (n − 1)n/2 + 1 + n = (n² − n + 2n)/2 + 1 = (n² + n)/2 + 1 = n(n+1)/2 + 1. Logo P(n). Por indução, P(n) vale para todo n ≥ 0.

COMPORTAMENTO ASSINTÓTICO (complemento):
L_n = (n² + n)/2 + 1 ∈ Θ(n²): existem c₁ = 1/2, c₂ = 1, n₀ = 2 tais que, para todo n ≥ 2, (1/2)n² ≤ L_n ≤ n². A desigualdade da esquerda vale para todo n ≥ 0, pois L_n − n²/2 = n/2 + 1 > 0. A da direita: n² − L_n = (n² − n − 2)/2 = (n − 2)(n + 1)/2 ≥ 0 para n ≥ 2. Em n = n₀ = 2: (1/2)·4 = 2 ≤ L_2 = 4 ≤ 4 = 2². Confere (com igualdade à direita).

Conferência numérica (Python; não faz parte da prova): conferem os valores da recorrência L_0..L_10 = 1, 2, 4, 7, 11, 16, 22, 29, 37, 46, 56, que a forma fechada n(n+1)/2 + 1 bate com eles para n = 0..39, que retas aleatórias (em posição geral, com probabilidade 1) produzem exatamente esses números de regiões para n = 0..10, e que com concorrência tripla o número cai (3 retas por um ponto dão 6), em acordo com o lema (k = 1 < 2, a terceira reta acrescenta só 2). Nada disso é prova; a prova é a das etapas 2 e 3.
