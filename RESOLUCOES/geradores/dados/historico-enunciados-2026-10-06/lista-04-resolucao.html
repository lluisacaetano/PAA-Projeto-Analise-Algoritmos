Questão 1 — provas por indução

Enunciado

Use o método da indução matemática para provar as assertivas abaixo.

(a) S(n) : 1 + 3 + 5 + … + (2·n − 1) = n², ∀n ≥ 1

(b) T(n) = 2 se n = 1; T(n) = 2T(n−1) se n ≥ 2. A fórmula fechada para essa recorrência é T(n) = 2n

(c) T(n) = 1 se n = 1; T(n) = T(n−1) + 1 se n ≥ 2. A fórmula fechada para essa recorrência é T(n) = n

(d) T(n) = 1 se n = 1; T(n) = T(n−1) + 3 se n ≥ 2. A fórmula fechada para essa recorrência é T(n) = 3·n − 2

(e) T(n) = 1 se n = 1; T(n) = T(n−1) + 2 se n ≥ 2. A fórmula fechada para essa recorrência ∈ Θ(n)

Uma observação de domínio que vale para (b), (c), (d) e (e), e que quase todo mundo pula. Cada recorrência está definida sobre os inteiros n ≥ 1 — não sobre n ≥ 0. A primeira cláusula fixa o valor em n = 1; a segunda, T(n) = … T(n−1) …, vem sob a condição “se n ≥ 2” e só pode ser aplicada quando o argumento é ≥ 2. Nos passos abaixo calcula-se T(n+1) com n ≥ 1; como n ≥ 1 implica n+1 ≥ 2, a segunda cláusula é aplicável — e é aí, e só aí, que a restrição de domínio é consumida. Uma prova que aplicasse a cláusula recursiva em n = 1 concluiria coisas sobre T(0), que não existe.

(a)   1 + 3 + 5 + … + (2n − 1) = n²

Proposição. Para cada inteiro n ≥ 1, seja P(n): ∑k=1n (2k − 1) = n². O somatório é a notação precisa para “1 + 3 + 5 + … + (2n − 1)”; em particular, para n = 1 a soma tem um único termo — a reticência não representa termo algum. É nesse sentido que a base é verificada.

Base (n = 1). Os dois lados, calculados separadamente: lado esquerdo = 2·1 − 1 = 1; lado direito = 1² = 1. Como 1 = 1, P(1) é verdadeira.

Hipótese (h.i.). Seja n ≥ 1 um inteiro fixado e suponha ∑k=1n (2k − 1) = n².

Passo. Separa-se o somatório até n+1 no somatório até n mais o termo k = n+1 — separação válida para todo n ≥ 0, inclusive quando a soma restante é vazia:

∑k=1n+1 (2k − 1) = [ ∑k=1n (2k − 1) ] + (2(n+1) − 1)

= n² + (2(n+1) − 1)  ← (h.i.) aplicada ao colchete

= n² + 2n + 1 = (n + 1)². ∎

Detalhe que vale um ponto: a condição de fronteira que de fato importa aqui não é a do somatório — separar o último termo vale mesmo quando o que sobra é a soma vazia — e sim a convenção declarada acima, de que em n = 1 a soma tem um único termo. É ali que a base do item se decide.

(b)   T(1) = 2, T(n) = 2T(n−1)  ⟹  T(n) = 2n

Base (n = 1). T(1) = 2 pela primeira cláusula; 21 = 2. Como 2 = 2, vale.

Hipótese. Seja n ≥ 1 fixado e suponha T(n) = 2n.

Passo. Como n ≥ 1, então n+1 ≥ 2, e é por isso que a segunda cláusula é aplicável ao argumento n+1:

T(n+1) = 2·T((n+1) − 1) = 2·T(n) = 2·2n  ← (h.i.)

= 2n+1. ∎

A armadilha do item. A mesma recorrência com base T(1) = 1 resolveria para 2n−1, não 2n. Aqui a base vale 2, e é a base que fixa a constante multiplicativa. Esse é exatamente o tipo de troca que o professor faz entre a lista e a prova (compare com a Q2(a) da prova de 2025, em que o + virou − e a resposta se inverteu).

(c)   T(1) = 1, T(n) = T(n−1) + 1  ⟹  T(n) = n

Base (n = 1). T(1) = 1 pela primeira cláusula; e n = 1. Como 1 = 1, vale.

Hipótese. Seja n ≥ 1 fixado e suponha T(n) = n.

Passo. Como n ≥ 1, então n+1 ≥ 2 e a segunda cláusula é aplicável ao argumento n+1:

T(n+1) = T((n+1) − 1) + 1 = T(n) + 1 = n + 1  ← (h.i.)  ∎

(d)   T(1) = 1, T(n) = T(n−1) + 3  ⟹  T(n) = 3n − 2

Base (n = 1). T(1) = 1 pela primeira cláusula; 3·1 − 2 = 3 − 2 = 1. Como 1 = 1, vale.

Hipótese. Seja n ≥ 1 fixado e suponha T(n) = 3n − 2.

Passo. Como n ≥ 1, então n+1 ≥ 2 e a segunda cláusula é aplicável:

T(n+1) = T((n+1) − 1) + 3 = T(n) + 3 = (3n − 2) + 3  ← (h.i.)

= 3n + 1 = 3n + 3 − 2 = 3(n + 1) − 2. ∎

Dois pontos que valem nota. Primeiro: a base é calculada, não declarada — é exatamente ali que uma fórmula quase certa como 3n − 3 ou 3n − 1 seria refutada. Segundo: a constante da hipótese (o −2) reaparece intacta na conclusão. Constante que “cresce” no meio do passo é o erro mais comum da técnica.

(e)   T(1) = 1, T(n) = T(n−1) + 2  ⟹  T(n) ∈ Θ(n)

O enunciado pede a classe Θ. O caminho é em duas fases: primeiro a indução dá a forma fechada, depois as testemunhas dão o Θ.

Fase 1 — forma fechada: T(n) = 2n − 1. De onde vem o palpite: desenrolando a recorrência, T(n) = T(n−1) + 2 = T(n−2) + 2·2 = … = T(1) + 2(n−1) = 1 + 2n − 2 = 2n − 1. O desenrolar é heurística, não demonstração — quem demonstra é a indução abaixo, que parte da definição recursiva e chega à fórmula.

Base (n = 1). T(1) = 1 pela primeira cláusula; 2·1 − 1 = 1. Como 1 = 1, vale.

Hipótese. Seja n ≥ 1 fixado e suponha T(n) = 2n − 1.

Passo. Como n ≥ 1, então n+1 ≥ 2 e a segunda cláusula é aplicável:

T(n+1) = T((n+1) − 1) + 2 = T(n) + 2 = (2n − 1) + 2  ← (h.i.)

= 2n + 1 = 2n + 2 − 1 = 2(n + 1) − 1. ∎

Fase 2 — de T(n) = 2n − 1 para T(n) ∈ Θ(n).

Pela definição (CLRS 3ª ed., §3.1), Θ(g(n)) é o conjunto das funções f para as quais existem constantes positivas c1, c2, n0 tais que, para todo n ≥ n0, vale 0 ≤ c1·g(n) ≤ f(n) ≤ c2·g(n). A ordem dos quantificadores é ∃c1 ∃c2 ∃n0 ∀n ≥ n0: as três constantes são escolhidas primeiro, de uma vez, e não podem depender de n.

Testemunhas: c1 = 1, c2 = 2, n0 = 1. Todas positivas (1 > 0, 2 > 0, 1 > 0) — condição da definição, não decorrência dela — e nenhuma contém n. Aqui f(n) = T(n) = 2n − 1 e g(n) = n.

Conferência em n = n0 = 1, exatamente. c1·g(1) = 1·1 = 1; T(1) = 2·1 − 1 = 1 (e T(1) = 1 pela recorrência — os dois caminhos concordam); c2·g(1) = 2·1 = 2. Logo 0 ≤ 1 ≤ 1 ≤ 2. Vale em n0, com igualdade na cota inferior — permitido, pois a definição usa ≤, não <.

Verificação para todo n ≥ 1 (algébrica, não amostral). Seja n inteiro com n ≥ 1.

(i) c1·g(n) = n ≥ 1 > 0, portanto 0 ≤ c1·g(n).

(ii) n ≤ 2n − 1 equivale, subtraindo n dos dois lados, a 0 ≤ n − 1, isto é 1 ≤ n — verdadeira por hipótese.

(iii) 2n − 1 ≤ 2n equivale, subtraindo 2n dos dois lados, a −1 ≤ 0 — verdadeira incondicionalmente.

Reunindo: para todo n ≥ 1, 0 ≤ 1·n ≤ 2n − 1 = T(n) ≤ 2·n. Portanto T(n) = 2n − 1 ∈ Θ(n). ∎

Θ(n) é teto e piso; não diz que T(n) = n. De fato T(n) ≠ n para n ≥ 2, e ainda assim T ∈ Θ(n) — é precisamente para isso que servem c1 e c2.

Questão 2 — limites assintóticos por Teorema Mestre

Enunciado

Indique o limite assintótico usando a notação Θ, para cada uma das equações de recorrência abaixo. Considere o caso base T(1) = 1 ou T(n) = c, para alguma constante c e ∀n ≤ n0, para alguma constante n0. Suponha, também, que n uma potência exata de b. Escolha o valor adequado para a constante b conforme a equação de recorrência a ser resolvida. Justifique todas as suas respostas. Respostas sem justificativas não serão consideradas.

(a) T(n) = 2T(n/3) + 1    (b) T(n) = 5T(n/4) + n    (c) T(n) = 7T(n/7) + n    (d) T(n) = 9T(n/3) + n²    (e) T(n) = 8T(n/2) + n³

O teorema na forma que a prova entrega

A prova desta disciplina fornece o Teorema Mestre na forma de Brassard & Bratley, que compara a com bk — não f(n) com nlogb a, como o CLRS. Hipóteses, como o formulário da prova as enuncia: a ≥ 1 e b ≥ 2 naturais, k ≥ 0, f(n) = c·nk com c > 0 real, n potência exata de b, e T assintoticamente não decrescente. A tabela abaixo está na mesma ordem em que a prova imprime os casos — assim “primeiro/segundo/terceiro caso” aponta para a linha certa com a folha na mesa.

casoComparaçãoConclusãoLeitura
1ºa < bkΘ(nk)a raiz domina
2ºa = bkΘ(nk · lg n)todos os níveis custam o mesmo
3ºa > bkΘ(nlogb a)as folhas dominam

O valor de b não é escolhido arbitrariamente: ele é lido no argumento da chamada recursiva. Se a chamada é T(n/3), então b = 3. “Escolher o valor adequado de b”, como diz o enunciado, significa usar essa base ao supor n = bm. Dentro de Θ a base do logaritmo é irrelevante, pois logx n = lg n / lg x e 1/lg x é constante positiva; escreve-se lg = log2.

Lema da expansão — onde a hipótese “n é potência exata de b” é usada

Aplicar a fórmula não é justificar. Como o enunciado garante que n é potência exata de b, dá para exibir a forma fechada exata e extrair dela as testemunhas. Isso vale para os cinco itens de uma vez.

O lema abaixo é enunciado com c = 1, que é o caso dos cinco itens desta questão. Para c > 0 qualquer, o termo motor fica multiplicado por c, mas o termo do caso base am não — de modo que Tc(n) = am + c·(T1(n) − am), e não c·T1(n). Por isso as testemunhas não se reescalam por um simples fator c: no caso a = bk ficam c1 = c/lg b, c2 = (1+c)/lg b, n0 = b; no caso a > bk ficam c1 = 1, c2 = 1 + c·B, n0 = 1. As classes Θ, que é o que importa aqui, não mudam.

Lema. Seja T(1) = 1 e T(n) = a·T(n/b) + nk para n > 1. Se n = bm com m ≥ 0 inteiro, então

T(bm) = am + ∑i=0m−1 ai · bk(m−i)

Base (m = 0). O lado direito vale a0 = 1 (a soma é vazia) e T(b0) = T(1) = 1. Confere.

Passo. Suponha a fórmula válida para m. Então

T(bm+1) = a·T(bm) + (bm+1)k = a·am + ∑i=0m−1 ai+1 bk(m−i) + bk(m+1)

Trocando o índice para j = i+1, a soma vira ∑j=1m aj bk(m+1−j); e o termo isolado bk(m+1) é exatamente a parcela j = 0 dessa mesma soma (substituindo j = 0 em ajbk(m+1−j) obtém-se 1·bk(m+1)). Logo

T(bm+1) = am+1 + ∑j=0m aj bk(m+1−j), ∎

que é a fórmula para m+1.

Onde a hipótese entra. Em cada um dos m desdobramentos, o argumento bm/bi = bm−i é inteiro, e a recursão atinge o caso base T(1) após exatamente m = logb n níveis. Sem essa hipótese apareceriam pisos e tetos ⌊n/b⌋, e a igualdade acima seria apenas aproximada — a conclusão Θ continuaria valendo, a forma fechada exata não.

Somando a série geométrica. Escrevendo bk(m−i) = bkm·(b−k)i, tem-se ∑i=0m−1 aibk(m−i) = bkm ∑i=0m−1 (a/bk)i, com bkm = (bm)k = nk e am = (bm)logb a = nlogb a.

Caso a = bk. A razão é 1, a soma tem m parcelas iguais a 1:

(F1)    T(n) = (m+1)·nk = nk·(logb n + 1)

Caso a ≠ bk. A soma geométrica de razão a/bk ≠ 1 vale ((a/bk)m − 1)/((a/bk) − 1). Multiplicando numerador e denominador por bk:

(F2)    T(n) = A·nlogb a − B·nk,   com A = a/(a − bk) e B = bk/(a − bk)

Dois corolários que dão as testemunhas

Corolário 1 — caso a > bk. Aqui a − bk > 0, logo A e B são positivos, e A − B = (a − bk)/(a − bk) = 1. Como a > bk implica logb a > k, o expoente k − logb a é negativo, e portanto nk−logb a ≤ 1 para todo n ≥ 1. Escrevendo T(n) = nlogb a·(A − B·nk−logb a):

1·nlogb a = (A−B)·nlogb a ≤ T(n) ≤ A·nlogb a,   ∀ n = bm ≥ 1

ou seja c1 = 1, c2 = A, n0 = 1. Isso é Θ(nlogb a). Checagem de consistência: em n = 1 a fórmula dá T(1) = A − B = 1, que é o caso base dado.

Corolário 2 — caso a = bk. De (F1), T(n) = nk·(lg n / lg b + 1). Para n ≥ b vale lg n ≥ lg b, isto é 1 ≤ lg n / lg b; portanto

(1/lg b)·nk lg n ≤ T(n) ≤ (2/lg b)·nk lg n,   ∀ n = bm ≥ b

ou seja c1 = 1/lg b, c2 = 2/lg b, n0 = b. Isso é Θ(nk lg n).

A restrição n0 = b não é cosmética — é o ponto de fencepost do item. Com n0 = 1 teríamos lg 1 = 0, e a cota superior viraria T(1) = 1 ≤ c2·0 = 0, que é falsa. Escrever n0 = 1 aqui perde o item inteiro.

(a)   T(n) = 2T(n/3) + 1

Identificação. A chamada é T(n/3) ⟹ b = 3. Há duas chamadas ⟹ a = 2. O termo não recursivo é 1 = 1·n0 ⟹ k = 0, c = 1. (Armadilha: o “+1” é n0, não n1.)

Comparação. bk = 30 = 1. Como 2 > 1, tem-se a > bk: terceiro caso.

T(n) ∈ Θ(nlog3 2), com log3 2 ≈ 0,630930. A forma exata log3 2 é a resposta; o decimal é só orientação.

Confirmação por expansão (n = 3m). Aqui a/bk = 2, e (F2) dá A = 2/(2−1) = 2, B = 1/(2−1) = 1:

T(3m) = 2m+1 − 1,   isto é   T(n) = 2·nlog3 2 − 1

Conferindo pela recorrência: T(3) = 2·T(1) + 1 = 3 = 2² − 1; T(9) = 2·3 + 1 = 7 = 2³ − 1.

Testemunhas (Corolário 1, A = 2): c1 = 1, c2 = 2, n0 = 1. A cota inferior nlog3 2 ≤ 2nlog3 2 − 1 equivale a nlog3 2 ≥ 1, verdadeira exatamente para n ≥ 1. Em n = n0 = 1: 1 ≤ 1 ≤ 2.

Cruzando com o CLRS. nlogb a = nlog3 2 e f(n) = 1 = O(nlog3 2 − ε) para ε = 0,5 > 0 (pois 0,630930 − 0,5 = 0,130930 > 0). Caso 1 do CLRS ⟹ mesma resposta.

(b)   T(n) = 5T(n/4) + n

Identificação. b = 4, a = 5, f(n) = n = 1·n1 ⟹ k = 1, c = 1.

Comparação. bk = 4. Como 5 > 4: terceiro caso.

T(n) ∈ Θ(nlog4 5), com log4 5 ≈ 1,160964.

Confirmação por expansão (n = 4m). a − bk = 1, logo A = 5, B = 4:

T(4m) = 5·5m − 4·4m,   isto é   T(n) = 5·nlog4 5 − 4n

Conferindo: T(4) = 5·1 + 4 = 9 e 5·5 − 4·4 = 9; T(16) = 5·9 + 16 = 61 e 125 − 64 = 61.

Testemunhas (Corolário 1, A = 5): c1 = 1, c2 = 5, n0 = 1. A cota inferior 5nα − 4n ≥ nα (com α = log4 5) equivale a nα−1 ≥ 1, com α − 1 ≈ 0,161 > 0 — verdadeira para todo n ≥ 1. Em n = n0 = 1: T(1) = 5 − 4 = 1, e 1 ≤ 1 ≤ 5. Em n = 4: 5 ≤ 9 ≤ 25.

Um susto que a forma fechada desfaz. A razão T(n)/nlog4 5 vale 1,80 · 2,44 · 2,95 · 3,36 · 3,69 · 3,95 · 4,16 · 4,33 em n = 41…48 — ainda subindo, o que parece divergência e sugeriria um fator logarítmico faltando. Não falta: a forma fechada dá T(n)/nα = 5 − 4·n1−α, monótona crescente e limitada por 5. A convergência é lenta só porque 1 − α ≈ −0,161 é pequeno em módulo. Ler tabela sem a forma fechada engana.

(c)   T(n) = 7T(n/7) + n

Identificação. b = 7, a = 7, k = 1, c = 1.

Comparação. bk = 7 = a: segundo caso.

T(n) ∈ Θ(n lg n).

Confirmação por expansão (n = 7m). Como a = bk, cada nível custa o mesmo: no nível i há 7i subproblemas de tamanho 7m−i, custo total 7i·7m−i = 7m = n por nível, para i = 0, …, m−1; as 7m = n folhas custam T(1) = 1 cada. Por (F1):

T(7m) = (m+1)·7m,   isto é   T(n) = n·(log7 n + 1) = (1/lg 7)·n lg n + n

Conferindo: T(7) = 7·1 + 7 = 14 = 2·7; T(49) = 7·14 + 49 = 147 = 3·49.

Testemunhas (Corolário 2, lg 7 ≈ 2,807355): c1 = 1/lg 7 ≈ 0,356207, c2 = 2/lg 7 ≈ 0,712414, n0 = 7. Em n = n0 = 7 exatamente: n lg n = 7·lg 7 ≈ 19,6515; c1·19,6515 ≈ 7,0 e c2·19,6515 ≈ 14,0. Como T(7) = 14, vale 7 ≤ 14 ≤ 14 — a cota superior é atingida com igualdade em n0, o que a definição permite (usa ≤), mas mostra que c2 não pode ser reduzido mantendo n0 = 7.

Por que NÃO é Θ(n) — a resposta errada plausível do conjunto. Com a = b = 7 a intuição sugere “n subproblemas de custo unitário, logo Θ(n)”. A forma fechada refuta: T(n)/n = log7 n + 1, que vale 2, 3, 4, 5 em n = 7, 49, 343, 2401 — diverge. Não existe c com T(n) ≤ c·n para todo n grande, logo T ∉ O(n) e, a fortiori, T ∉ Θ(n). O fator lg n vem do número de níveis, não do custo por nível.

(d)   T(n) = 9T(n/3) + n²

Identificação. b = 3 (lido no argumento n/3), a = 9, f(n) = n² = 1·n2 ⟹ k = 2.

Comparação. bk = 3² = 9 = a: segundo caso.

T(n) ∈ Θ(n² lg n).

Confirmação por expansão (n = 3m). No nível i há 9i subproblemas de tamanho 3m−i, custo 9i·(3m−i)² = 9i·9m−i = 9m = n² — custo idêntico em todos os níveis. Por (F1), usando 9m = (3m)² = n²:

T(3m) = (m+1)·9m,   isto é   T(n) = n²·(log3 n + 1)

Conferindo: T(3) = 9·1 + 9 = 18 = 2·9; T(9) = 9·18 + 81 = 243 = 3·81.

Testemunhas (Corolário 2, lg 3 ≈ 1,584963): c1 = 1/lg 3 ≈ 0,630930, c2 = 2/lg 3 ≈ 1,261860, n0 = 3. Em n = n0 = 3 exatamente: n² lg n = 9·lg 3 ≈ 14,2647; as cotas dão ≈ 9,0 e ≈ 18,0; com T(3) = 18, vale 9 ≤ 18 ≤ 18.

(e)   T(n) = 8T(n/2) + n³

Identificação. b = 2, a = 8, k = 3.

Comparação. bk = 2³ = 8 = a: segundo caso.

T(n) ∈ Θ(n³ lg n).

Confirmação por expansão (n = 2m). No nível i: 8i subproblemas de tamanho 2m−i, custo 8i·(2m−i)³ = 8m = n³ por nível. Por (F1), com b = 2 não há fator de conversão (log2 n = lg n):

T(2m) = (m+1)·8m,   isto é   T(n) = n³·(lg n + 1) = n³ lg n + n³

Conferindo: T(2) = 8·1 + 8 = 16 = 2·8; T(4) = 8·16 + 64 = 192 = 3·64.

Testemunhas (Corolário 2, lg 2 = 1): c1 = 1, c2 = 2, n0 = 2. Em n = n0 = 2 exatamente: n³ lg n = 8·1 = 8; as cotas dão 8 e 16; com T(2) = 16, vale 8 ≤ 16 ≤ 16.

O caso base não muda nenhuma das respostas

O enunciado admite T(1) = 1 ou T(n) = c para todo n ≤ nbase. Refazendo o Lema com T(1) = c, o único termo afetado é am·T(1) = c·am:

(a) (c+1)nlog3 2 − 1  ·  (b) (c+4)nlog4 5 − 4n  ·  (c) n(log7 n + c)  ·  (d) n²(log3 n + c)  ·  (e) n³(lg n + c)

Cuidado com o símbolo. Aqui c é a constante do caso base, não o coeficiente do termo motor — e os dois papéis dão testemunhas diferentes. Com T(1) = c a razão T(n)/(nk lg n) vale 1/lg b + c/lg n, cujo ínfimo é 1/lg b e não depende de c; no regime do termo motor a razão é 1/lg n + c/lg b, com ínfimo c/lg b. Trocar um pelo outro produz uma cota inferior falsa: no item (e) com c = 3 tem-se T(4) = 320, e a cota c/lg b exigiria 384.

Questão 3 — a prova por indução defeituosa

Enunciado

Considere a seguinte prova por indução matemática:

  1. Proposição. Dado um conjunto de n pessoas, se pelo menos uma pessoa tem a nacionalidade chinesa, então todas os demais pessoas também são chinesas.
  2. Caso base (n = 1): Em um conjunto com uma pessoa, se ela é chinesa, então todas as pessoas do conjunto são chinesa. Portanto, a afirmação é verdadeira.
  3. Hipótese de indução:
    • Suponha que a proposição é verdadeira para n = 3;
    • Sejam T1, T2, T3 e T4 quatro pessoas das quais pelo menos uma tem nacionalidade chinesa (suponha que é T1);
    • Supondo que o conjunto {T1, T2, T3} é a hipótese de que é verdadeiro para n = 3, então T2 e T3 são pessoas com nacionalidade chinesa;
    • Analogamente para {T1, T2, T4}, tem-se que T2 e T4 são pessoas com nacionalidade chinesa.
    Portanto, as quatro pessoas tem nacionalidade chinesa! A generalização da construção para k e k + 1 é a prova desejada.

Pergunta: Essa prova está correta? Justifique formalmente sua resposta.

Transcrição literal do PDF do professor, inclusive as concordâncias “todas os demais pessoas” e “são chinesa”.

Não, a prova não está correta. São dois defeitos, e vale separá-los. O imediato, no texto tal como escrito: ele supõe P(3), que nunca foi derivada da base P(1), e apresenta a conclusão como fato categórico — de modo que o máximo que estabelece é a implicação P(3) → P(4). O de fundo, que aparece ao completar a generalização que o texto delega a um “analogamente”: a proposição que ela pretende demonstrar é falsa. Como o Princípio da Indução Finita é uma regra de inferência correta — de premissas verdadeiras nunca extrai conclusão falsa —, uma “demonstração” de proposição falsa tem obrigatoriamente ao menos uma premissa não estabelecida. Abaixo: a refutação da proposição, a localização exata da premissa que falha, os defeitos adicionais de redação e o diagnóstico estrutural.

0. Notação

Para cada inteiro n ≥ 1, seja

P(n): “em todo conjunto C de n pessoas, se existe pelo menos uma pessoa chinesa em C, então todas as pessoas de C são chinesas”.

Duas observações que decidem tudo o que vem depois: P(n) é uma afirmação universal sobre todos os conjuntos de tamanho n, e cada instância é uma implicação (antecedente: “há pelo menos um chinês”; consequente: “todos são chineses”).

1. A proposição é falsa — contraexemplo

Tome n = 2 e C = {T1, T2}, com T1 de nacionalidade chinesa e T2 de nacionalidade brasileira. O antecedente é verdadeiro (T1); o consequente é falso (T2 não é). Implicação com antecedente verdadeiro e consequente falso é falsa: P(2) é falsa. O mesmo contraexemplo — C = {T1 chinês, T2, …, Tn não-chineses} — refuta P(n) para qualquer n ≥ 2 para o qual existam n pessoas; e é P(2) que o resto desta resposta usa.

A tabela supõe pessoas em número suficiente para formar cada conjunto — num universo com menos de n pessoas, P(n) seria vacuamente verdadeira, por falta de conjunto a testar. Isso não socorre a prova: o que ela precisaria é de P(2), e P(2) é falsa em qualquer universo com ao menos uma pessoa chinesa e ao menos uma não-chinesa.

Como a conclusão pretendida — “P(n) para todo n” — é falsa, o veredito está encerrado. O que resta é responder onde.

2. Localização exata do defeito

2.1 Reconstrução do passo. O texto não escreve o passo genérico — diz “a generalização … é a prova desejada”. Mas a construção exibida em 3 → 4 tem uma generalização natural (e o item 2.4 mostra que a conclusão não depende de qual escolha de elementos removidos se adote):

Seja k ≥ 1 e suponha P(k). Seja S = {T1, …, Tk+1} com pelo menos uma pessoa chinesa; sem perda de generalidade, T1. Defina A = S∖{Tk+1} e B = S∖{Tk}. Então |A| = |B| = k e A ∪ B = S. Aplicando P(k) a A e a B, e usando A ∪ B = S, conclui-se P(k+1).

No texto, k = 3: A = {T1,T2,T3} e B = {T1,T2,T4}.

2.2 A condição exata de aplicabilidade da hipótese. P(k) é uma implicação. Aplicá-la a um conjunto X com |X| = k só produz “todos de X são chineses” se o antecedente estiver verificado para X — isto é, se soubermos que X contém pelo menos uma pessoa chinesa. Ter |X| = k não basta.

A sutileza é que a lista de pessoas sabidamente chinesas cresce ao longo do argumento. No início a única testemunha é T1; mas ao aplicar P(k) a A, que contém T1, todo elemento de A passa a ser sabidamente chinês — e então qualquer elemento de A ∩ B serve de testemunha para a segunda aplicação. Com a rotulação de 2.1 — A é o primeiro subconjunto a receber a hipótese —, o passo exige T1 ∈ A e A ∩ B ≠ ∅. Mas T1 ∈ A ∪ B = S sempre vale, de modo que chamar de A aquele que contém T1 é escolha de rótulo, não exigência. A condição substantiva — a única que pode falhar — é:

A ∩ B ≠ ∅

(Exigir T1 ∈ A ∩ B também funcionaria, mas é forte demais: para k = 3 o par A = {T1,T2,T3}, B = {T2,T3,T4} fecha o passo sem que T1 esteja em B.)

Na construção do texto, a conta é imediata:

A ∩ B = S∖{Tk, Tk+1} = {T1, …, Tk−1},   com   |A ∩ B| = k − 1

Logo A ∩ B ≠ ∅ se e somente se k ≥ 2. A cardinalidade nem depende da rotulação: |A| = |B| = k e |A ∪ B| = k + 1 forçam |A ∩ B| = 2k − (k+1) = k − 1.

2.3 O caso k = 1, onde tudo desaba. Para k = 1 temos S = {T1, T2} com T1 chinês, e a construção dá A = {T1}, B = {T2}.

Aplicar P(1) a A é legítimo, mas conclui apenas “T1 é chinês” — nada de novo.

Aplicar P(1) a B é ilegítimo: não se sabe que T2 é chinês — esse é exatamente o fato que se quer provar. O antecedente de P(1) para B não está verificado, e de P(1) nada se deduz sobre B. Insistir seria usar a tese para provar a tese.

Consequentemente S = A ∪ B não fica coberto: sobre T2 não se obteve nada.

Conclusão: a implicação P(1) → P(2) não é demonstrada pela construção. É o único elo faltante — e, pelo item 1, é também um elo falso (P(1) verdadeira, P(2) falsa). Não há remendo possível: não se trata de prova malfeita de algo verdadeiro, e sim da tentativa de provar algo falso.

2.4 O defeito não depende da rotulação. Qualquer versão dessa construção obtém os dois subconjuntos de tamanho k removendo de S dois elementos distintos (removendo o mesmo duas vezes teríamos A = B e A ∪ B ≠ S, e o argumento nem cobriria S). Removendo dois elementos distintos de um conjunto de k+1 = 2 elementos, os subconjuntos resultantes são forçosamente os singletons {T1} e {T2}, que são disjuntos — e sem interseção não há como transportar testemunha de um para o outro, qualquer que seja a rotulação.

3. Defeitos adicionais de redação

(a) A hipótese foi enunciada para um valor fixo. O texto escreve “suponha que a proposição é verdadeira para n = 3”. Isso não é hipótese de indução legítima: a hipótese é “seja k ≥ n0 arbitrário e suponha P(k)”. Duas regras trabalham juntas — descarregar a hipótese P(k) é o que produz a implicação P(k) → P(k+1), e a arbitrariedade de k é o que autoriza a generalização universal, ∀k (P(k) → P(k+1)). Fixando n = 3, a primeira ainda se aplica — assumir P(3), derivar P(4) e descarregar produz legitimamente a implicação P(3) → P(4) — mas a segunda não: sem k arbitrário não há generalização universal. É por isso que o texto fica preso a essa única implicação concreta.

(b) P(3) nunca foi estabelecida — e é falsa. O caso base provado é P(1); nada liga P(1) a P(3). Sutileza importante: supor P(3) dentro de uma prova condicional não é falácia — obtém-se legitimamente a implicação P(3) → P(4). A falácia está em concluir o consequente de uma prova condicional sem ter estabelecido o antecedente — modus ponens sem a premissa menor: a frase “Portanto, as quatro pessoas tem nacionalidade chinesa!” é apresentada como fato categórico quando só vale sob uma hipótese não demonstrada.

(c) O rótulo está trocado. O que o texto chama de “hipótese de indução” é o passo indutivo, e apenas na instância concreta 3 → 4. Enunciar a hipótese dentro do passo é prática comum e não seria defeito; o defeito é o rótulo esconder que ali está sendo feita justamente a parte que precisaria de k arbitrário — e a quantificação universal sobre k nunca aparece.

(d) “A generalização … é a prova desejada” é um buraco, não um passo. É o padrão “analogamente / claramente”: a frase ocupa exatamente o lugar onde a demonstração deveria estar — e é precisamente onde a prova falha. Se o autor tivesse escrito o passo genérico com os quantificadores explícitos, seria obrigado a justificar que A ∩ B ≠ ∅ — na construção do texto, que T1 ∈ B — e o caso k = 1 apareceria imediatamente.

(e) Base e passo não se encaixam. A base é n = 1; o passo só funciona de k = 2 em diante.

4. Diagnóstico estrutural: por que o dominó não cai

O texto do professor não escreve o passo genérico — exibe só a instância 3 → 4 e delega o resto a um “analogamente”. Completando-o como em 2.1, com a aplicabilidade da hipótese verificada como em 2.2, dá para separar o que fica de pé do que não fica. A indução é uma cadeia de implicações ancorada na base:

P(1) → P(2) → P(3) → P(4) → …

PeçaStatus
Base: P(1)verdadeira ✔
Passo: P(k) → P(k+1) para todo k ≥ 2demonstrável — mas pela reconstrução de 2.1, não pelo texto ✔
Elo P(1) → P(2)não demonstrado — e falso ✘

O primeiro dominó cai e os do segundo em diante estão bem posicionados uns em relação aos outros, mas ninguém empurra o segundo. A única instância P(n) inferível dessas premissas é P(1).

Por que “base válida + passo válido para quase todo k” não basta. O argumento decisivo é um contramodelo. Tome um mundo com pelo menos uma pessoa chinesa e pelo menos uma não-chinesa — T1 chinês, T2 brasileiro, e quantas mais se queira. Confira nele as premissas oferecidas:

(i) P(1) é verdadeira, logo a base vale — de fato P(1) é verdadeira em todo mundo;

(ii) P(k) → P(k+1) vale para todo k ≥ 2, logo o passo vale — a derivação de 2.1 é correta sempre que k ≥ 2, qualquer que seja o mundo;

(iii) e, no entanto, ∀n P(n) é falsa, pois P(2) falha pelo contraexemplo do item 1.

Existe, portanto, um modelo que satisfaz todas as premissas oferecidas e refuta a conclusão. Logo essas premissas não implicam a conclusão — nenhuma reescrita da prova poderia salvá-la. E, coerentemente, a única implicação da cadeia que é falsa nesse modelo é exatamente P(1) → P(2), a que o texto não demonstrou.

Lição geral. Uma única lacuna em k = m corta a cadeia, e nada a respeito de n > m fica demonstrado — a menos que se prove independentemente uma nova base acima de m. Aqui não há base a resgatar: qualquer nova base teria de recuperar P(2) para cobrir n = 2, e P(2) é falsa pelo contraexemplo do item 1.

5. O nome do padrão, e a regra de higiene

É o disfarce brasileiro de um clássico. A falácia foi levantada por George Pólya em Induction and Analogy in Mathematics (1954), na forma “quaisquer n moças têm olhos da mesma cor”; a formulação que ficou famosa — “todos os cavalos têm a mesma cor” — é creditada a Joel E. Cohen (1961). A anatomia é idêntica à desta questão: base em n = 1 e passo por dois subconjuntos de tamanho n−1, que só têm elemento em comum quando n − 1 ≥ 2.

O que o Princípio da Indução Finita realmente exige. Seja P(n) propriedade sobre os inteiros e n0 ∈ ℤ. Se (1) P(n0) é verdadeira e (2) para todo inteiro k ≥ n0 vale P(k) → P(k+1), então P(n) é verdadeira para todo n ≥ n0. A quantificação em (2) é universal e sem exceções: o passo tem de valer para todo k a partir de n0, começando no próprio n0. Uma demonstração do passo que use, ainda que tacitamente, uma hipótese extra — aqui k ≥ 2, disfarçada na suposição não declarada de que A ∩ B ≠ ∅ (na construção do texto, de que T1 ∈ B) — estabelece apenas o passo restrito a esse domínio.

Regra de higiene, que é o que transfere para a prova. Em toda prova por indução, substitua k = n0 literalmente no passo e refaça a conta, em vez de confiar no k genérico. Neste exercício, k = 1 destrói a prova em duas linhas — e foi por não fazer esse teste, escondendo o caso geral atrás de um “a generalização … é a prova desejada”, que o argumento pareceu convincente. É o mesmo ataque de fencepost que decide as Questões 1 e 2.

Questão 4 — soma dos quadrados

Enunciado

Prove a proposição P(n) = 12 + 22 + 32 + ... + n2 = n ∗ (n + 1) ∗ (2n + 1)/6 usando o método da indução matemática.

1² + 2² + … + n² = n(n+1)(2n+1)/6, para todo n ≥ 1

Suposições declaradas. (1) O enunciado escreve “P(n) = …”, mas P(n) é uma proposição, não um número. Lê-se P(n): 1² + 2² + … + n² = n(n+1)(2n+1)/6. (2) O enunciado não fixa o domínio de n. Supõe-se n inteiro, n ≥ 1, que é o menor valor em que a soma escrita “1² + 2² + … + n²” tem ao menos o termo 1². (A identidade também vale em n = 0, lendo o lado esquerdo como soma vazia, igual a 0: 0·1·1/6 = 0. Isso não é necessário para o que se pede.) (3) Em notação de somatório, P(n): Σk=1n k² = n(n+1)(2n+1)/6.

Princípio usado. Se P(1) é verdadeira e, para todo inteiro n ≥ 1, P(n) implica P(n+1), então P(n) é verdadeira para todo inteiro n ≥ 1.

Base (n = 1). Lado esquerdo: 1² = 1. Lado direito: 1·(1+1)·(2·1+1)/6 = 1·2·3/6 = 6/6 = 1. Como 1 = 1, P(1) é verdadeira.

Hipótese de indução. Seja n ≥ 1 um inteiro fixado, e suponha P(n): Σk=1n k² = n(n+1)(2n+1)/6.

Passo. Quer-se P(n+1): Σk=1n+1 k² = (n+1)((n+1)+1)(2(n+1)+1)/6 = (n+1)(n+2)(2n+3)/6. Separa-se o último termo da soma:

Σk=1n+1 k² = [Σk=1n k²] + (n+1)² = n(n+1)(2n+1)/6 + (n+1)²  ← hipótese aplicada ao colchete

= [n(n+1)(2n+1) + 6(n+1)²]/6 = (n+1)·[n(2n+1) + 6(n+1)]/6  ← fator comum (n+1)

= (n+1)·(2n² + n + 6n + 6)/6 = (n+1)(2n² + 7n + 6)/6.

Fatorando o trinômio: (n+2)(2n+3) = 2n² + 3n + 4n + 6 = 2n² + 7n + 6. Logo Σk=1n+1 k² = (n+1)(n+2)(2n+3)/6, que é exatamente o lado direito de P(n+1). Portanto P(n) implica P(n+1), para todo n ≥ 1.

Conclusão. Pelo princípio da indução matemática, P(n) é verdadeira para todo inteiro n ≥ 1. ∎

Conferência de fencepost. n = 1: 1 = 1 (base). n = 2: 1 + 4 = 5 e 2·3·5/6 = 5. n = 3: 1 + 4 + 9 = 14 e 3·4·7/6 = 14. O passo com n = 1 (o menor valor em que é aplicado): 1·2·3/6 + 2² = 1 + 4 = 5 = 2·3·5/6. É a mesma identidade do IFMG, ex. 1, do banco de questões (lá escrita a partir de 0²).

Questão 5 — a prova defeituosa sobre árvores

Enunciado

Considere a proposição P(n): Toda árvore com n vértices possui exatamente n-1 arestas.

Um estudante apresentou a seguinte prova por indução.

Caso base. Para n = 1, uma árvore possui um único vértice e nenhuma aresta. Portanto, 0 = 1 − 1, e a afirmação é verdadeira para n = 1.

Hipótese de indução. Suponha que toda árvore com n vértices possua exatamente n−1 arestas.

Passo indutivo. Considere uma árvore T com n vértices. Pela hipótese de indução, T possui n − 1 arestas. Acrescente a T um novo vértice v e ligue-o, por meio de uma única aresta, a algum vértice de T. O novo vértice v é uma folha, e o grafo resultante continua sendo uma árvore. Assim, a nova árvore possui n + 1 vértices e (n − 1) + 1 = n arestas. Como n = (n + 1) − 1, conclui-se que toda árvore com n + 1 vértices possui n arestas. Logo, pelo princípio da indução matemática, toda árvore com n vértices possui exatamente n − 1 arestas.

Pergunta: Embora a afirmação seja verdadeira, a prova acima é logicamente incorreta. Identifique precisamente o erro no passo indutivo e explique por que a construção apresentada não é suficiente para demonstrar que toda árvore com n + 1 vértices possui n arestas.

O erro está no passo indutivo: ele parte de uma árvore T com n vértices e constrói, pendurando uma folha, UMA árvore com n + 1 vértices; prova assim a propriedade apenas para as árvores de n + 1 vértices obtidas por essa construção, e conclui para TODAS, sem provar que toda árvore com n + 1 vértices pode ser obtida assim. P(n+1) é universal e exige partir de uma árvore ARBITRÁRIA T' com n + 1 vértices; o caminho natural é reduzi-la a n vértices. A construção não basta porque a mesma forma de argumento “prova” a afirmação falsa “todo grafo com n ≥ 2 vértices, todos de grau ≥ 1, é conexo” (contraexemplo: duas arestas disjuntas, 4 vértices). O conserto: toda árvore com n + 1 ≥ 2 vértices tem uma folha v (caminho máximo), T' − v é árvore com n vértices, e a hipótese dá |E(T')| = (n − 1) + 1 = n.

Convenções. Grafo simples, finito. Árvore = grafo conexo e acíclico. Folha = vértice de grau 1. n é inteiro, n ≥ 1.

1. O que o passo indutivo precisa provar

Fixado n ≥ 1 e suposta a hipótese de indução, o passo precisa estabelecer P(n+1), que é uma afirmação universal:

P(n+1):   para TODA árvore T' com n + 1 vértices, |E(T')| = n.

Para provar uma afirmação universal, parte-se de um objeto ARBITRÁRIO da classe — uma árvore T' qualquer com n + 1 vértices — e mostra-se que ele tem a propriedade.

2. O que o passo do estudante efetivamente prova

O texto parte de uma árvore T com n vértices, escolhe um vértice u de T, e forma T + v (novo vértice v e aresta uv). Mostra que T + v tem (n − 1) + 1 = n arestas. O que fica provado é:

para toda árvore T com n vértices e todo vértice u de T, a árvore T + v tem n arestas.

Isto é, a propriedade vale para as árvores de n + 1 vértices QUE SÃO OBTIDAS por esta construção. A frase final — “conclui-se que toda árvore com n + 1 vértices possui n arestas” — troca “toda árvore construída assim” por “toda árvore”. Essa troca só seria legítima se estivesse provado que TODA árvore com n + 1 vértices pode ser obtida pendurando uma folha em alguma árvore de n vértices. Esse fato não é enunciado nem provado em lugar nenhum do texto.

3. O erro, com precisão

O passo começa numa árvore de n vértices e CONSTRÓI uma de n + 1 (n → n + 1). Construir não é, por si só, inválido; mas, assim, o passo cobre apenas a imagem da construção, e conclui sobre a classe inteira sem mostrar que a imagem é a classe inteira. O caminho que evita essa lacuna é o inverso: começar numa árvore ARBITRÁRIA de n + 1 vértices e REDUZI-LA a uma de n vértices, onde a hipótese se aplica (n + 1 → n).

É um erro de quantificador: prova-se “∀T ∀u: T + v tem n arestas” e conclui-se “∀T' com n + 1 vértices: T' tem n arestas”, sem o elo “∀T' ∃T ∃u: T' = T + v” (igualdade a menos do nome dos vértices). (Esse padrão é conhecido em inglês como build-up error, “erro de construção”.)

4. Por que a construção não basta: a mesma forma de argumento prova uma falsidade

Se o argumento do estudante fosse válido pela sua forma, a mesma forma provaria qualquer coisa com a mesma estrutura. Considere a afirmação FALSA

C(n): todo grafo com n vértices, todos de grau ≥ 1, é conexo    (n ≥ 2).

“Prova” com a mesma forma. Base (n = 2): o único grafo simples com 2 vértices, ambos de grau ≥ 1, é a aresta única, que é conexo; C(2) vale. Hipótese: todo grafo com n vértices, todos de grau ≥ 1, é conexo. “Passo”: tome um grafo G com n vértices, todos de grau ≥ 1; pela hipótese, G é conexo. Acrescente um novo vértice v ligado por uma aresta a algum vértice de G. O novo grafo tem n + 1 vértices, todos de grau ≥ 1, e é conexo (v está ligado a G, que é conexo). “Logo” todo grafo com n + 1 vértices, todos de grau ≥ 1, é conexo.

Mas C(4) é falsa: o grafo com vértices {1, 2, 3, 4} e arestas {1,2} e {3,4} tem todos os graus iguais a 1 e não é conexo. A construção nunca produz esse grafo: ela parte de um grafo de 3 vértices com todos os graus ≥ 1, e remover qualquer vértice de {1,2},{3,4} deixa um vértice de grau 0 — logo ele não é imagem da construção. O passo “construtivo” só enxergou os grafos que ele mesmo gera.

Portanto a forma de argumento usada pelo estudante é inválida; que a proposição P(n) sobre árvores seja verdadeira é um fato que a prova do estudante não estabelece.

5. O conserto: partir de uma árvore arbitrária com n + 1 vértices

Lema 1. Toda árvore com m ≥ 2 vértices tem uma folha.
Prova. Seja T' árvore com m ≥ 2 vértices. Como T' é conexa e tem pelo menos dois vértices, tem pelo menos uma aresta; logo existem caminhos com pelo menos uma aresta. Seja P = x0x1…xk um caminho de comprimento máximo em T' (existe, pois T' é finita e todo caminho tem no máximo m vértices); k ≥ 1. Todo vizinho de x0 está em P: se x0 tivesse um vizinho y fora de P, yx0x1…xk seria caminho mais longo. Se x0 fosse vizinho de xi com i ≥ 2, então x0x1…xix0 seria um ciclo, impossível em árvore. Logo o único vizinho de x0 é x1, e grau(x0) = 1. ∎

Lema 2. Se v é folha de uma árvore T' com m ≥ 2 vértices, então T' − v (remove-se v e a única aresta incidente a v) é uma árvore com m − 1 vértices.
Prova. Acíclico: todo ciclo de T' − v seria ciclo de T'. Conexo: sejam x, y vértices de T' − v. Em T' existe um caminho de x a y. Um vértice interno de um caminho tem grau ≥ 2 dentro dele; como grau(v) = 1 e v ∉ {x, y}, v não está nesse caminho, que portanto está inteiro em T' − v. ∎

Passo correto. Seja n ≥ 1 e suponha a hipótese de indução (toda árvore com n vértices tem n − 1 arestas). Seja T' uma árvore ARBITRÁRIA com n + 1 vértices. Como n + 1 ≥ 2, pelo Lema 1 T' tem uma folha v. Pelo Lema 2, T = T' − v é árvore com n vértices; pela hipótese de indução, |E(T)| = n − 1. Como v tem grau 1, T' tem exatamente uma aresta a mais que T: |E(T')| = (n − 1) + 1 = n. Como T' era arbitrária, P(n+1) vale. Com a base do estudante (que está correta), a indução fica completa. ∎

6. Observações

Para árvores, a imagem da construção É a classe inteira: pelos Lemas 1 e 2, toda árvore T' com n + 1 ≥ 2 vértices é (T' − v) + v. Por isso a conclusão é verdadeira. Mas esse fato é exatamente o conteúdo dos Lemas 1 e 2 — o trabalho que o estudante deixou de fazer.

A afirmação do estudante de que “o grafo resultante continua sendo uma árvore” é verdadeira (conexo porque v se liga a T conexa; acíclico porque um ciclo passando por v exigiria grau(v) ≥ 2, e um ciclo que não passa por v estaria inteiro em T, que é acíclica), mas foi dada sem justificativa. É uma lacuna menor; não é ela que invalida a prova.

A base e a hipótese de indução do estudante estão corretas; o erro está só no passo.

Comparação com a Questão 3. As duas são provas defeituosas, mas por motivos diferentes. Na Questão 3 o passo não vale num valor específico (k = 1), e a proposição é falsa. Aqui o passo vale para cada árvore construída, e a proposição é verdadeira: o defeito é concluir sobre uma classe inteira a partir de uma construção que não se provou cobrir a classe.

Dada uma árvore binária A com n nós, calcular o fator de balanceamento (f.b.) de cada nó — a altura da subárvore esquerda menos a da direita. Convenção: árvore vazia tem altura −1 e f.b. zero. A hipótese de indução fortalecida (“sabemos calcular f.b. e alturas de árvores com menos que n nós”) leva ao algoritmo:

▷ Saída: a árvore A com os f.b.s nos seus nós, e a altura de A

2. senão

O slide analisa o pior caso como a cadeia (ne ou nd sempre zero) e obtém Θ(n). E então deixa em aberto:

Exercício: “Há algum ganho em complexidade quando ambos ne e nd são aproximadamente n/2 ao longo da recursão?”

Não há ganho algum de complexidade de tempo — e o resultado é mais forte que “mesma classe assintótica”: o custo é idêntico, não apenas da mesma ordem. O que o balanceamento melhora, e melhora muito, é a profundidade da pilha, que cai de Θ(n) para Θ(lg n) — ganho de espaço, não de tempo.

1. Modelo de custo

Duas constantes positivas, fixas e uniformes sobre todas as chamadas — é o que os Θ(1) do slide escondem, e explicitá-las é necessário para poder somar um número variável delas:

a > 0: custo de uma chamada com A vazia (linha 1 e a devolução)

b > 0: custo da parte não recursiva de uma chamada com A não vazia (linha 1 e linhas 3, 7, 8, 9)

A recorrência estrutural exata é T(A) = a se A é vazia, e T(A) = b + T(Ae) + T(Ad) caso contrário.

2. O caso balanceado pelo Teorema Mestre

Com ne ≈ nd ≈ n/2 a recorrência vira T(n) = 2·T(n/2) + Θ(1). Para não colidir com as constantes de custo a e b, escrevo os parâmetros do teorema como α (número de chamadas recursivas), β (fator de redução) e k, na forma T(n) = α·T(n/β) + c·nk, com o critério α ≷ βk.

βk = 20 = 1 e α = 2, logo α > βk — o terceiro dos três casos, na ordem em que o formulário da prova os imprime. Portanto

T(n) = Θ(nlogβ α) = Θ(nlog2 2) = Θ(n)

Detalhe de rigor: o teorema pede um termo motor literalmente c·nk, não um Θ(1). Contorna-se enquadrando: existem d1 = min(a,b) e d2 = max(a,b) com 2T(n/2) + d1 ≤ T(n) ≤ 2T(n/2) + d2; aplicando o teorema ao lado esquerdo sai Ω(n), ao direito O(n), e juntos Θ(n). É a mesma classe do caso degenerado que o slide já resolveu.

3. A razão estrutural: a forma da árvore é irrelevante para o custo

As duas contas acima cobrem apenas os dois extremos. O que segue vale para toda árvore binária, e é a resposta de verdade.

Teorema. Para toda árvore binária A com n ≥ 0 nós, T(A) = (n+1)·a + n·b, qualquer que seja a forma de A.

Prova, por indução forte em n.

Base (n = 0). A é vazia; por definição T(A) = a. A fórmula dá (0+1)a + 0·b = a. ✓

Passo (n ≥ 1). Suponha a fórmula válida para toda árvore com estritamente menos que n nós — a hipótese forte é necessária, porque não se sabe como os n−1 nós se repartem. Seja A com n nós, subárvores Ae com ne nós e Ad com nd. Como a raiz não está em nenhuma das duas, ne + nd = n − 1; e como n ≥ 1, vale ne, nd ≤ n−1 < n, logo a hipótese se aplica às duas. Então

T(A) = b + [(ne+1)a + neb] + [(nd+1)a + ndb]

= b + (ne + nd + 2)·a + (ne + nd)·b

= b + (n+1)·a + (n−1)·b  ← usando ne + nd = n − 1

= (n+1)·a + n·b. ∎

Corolário. Tomando a = b = 1, o número total de invocações de FatorAltura numa árvore de n nós é exatamente 2n + 1: n chamadas com árvore não vazia (uma por nó) e n + 1 com árvore vazia — que são exatamente os n+1 ponteiros nulos de uma árvore binária de n nós. Casos pequenos: n = 0 → 1; n = 1 → 3 (a raiz e os dois filhos vazios).

Consequência. Escrever “T(n)” para um algoritmo cujo custo dependesse da forma da entrada só faria sentido como pior caso. Aqui o custo depende só de n: T(n) é função genuína de n, e pior caso = melhor caso = caso médio. Não há forma de árvore boa nem ruim.

Testemunhas. Com T(n) = (a+b)n + a: c1 = a + b, c2 = 2a + b, n0 = 1. Em n = n0 = 1 exatamente: T(1) = 2a + b; a cota inferior dá a + b ≤ 2a + b ⟺ 0 ≤ a ✓ (estrito, pois a > 0), e a superior 2a + b ≥ 2a + b ✓ com igualdade. No modelo unitário (a = b = 1): T(n) = 2n + 1, c1 = 2, c2 = 3, n0 = 1; em n = 1: 2 ≤ 3 ≤ 3; em n = 5: 10 ≤ 11 ≤ 15.

4. Por que tinha de ser assim — e o contraste que torna isso não trivial

O algoritmo faz, por nó, uma quantidade fixa de trabalho: uma subtração, um max, uma soma. Nenhum nó é visitado duas vezes e nenhum é pulado — é um percurso em pós-ordem disfarçado de recorrência. A forma da árvore redistribui as n unidades de trabalho entre os níveis, mas não muda quantas são.

O contraste: se o passo de combinação custasse Θ(tamanho da subárvore) em vez de Θ(1) — como no MergeSort —, a forma importaria muito: cadeia daria Θ(n²) e balanceada Θ(n lg n). O que anula o efeito da forma aqui é especificamente o custo de combinação ser constante.

Cota inferior do problema. Qualquer algoritmo correto precisa escrever um f.b. em cada um dos n nós, logo executa Ω(n) operações (testemunhas: ao menos 1 escrita por nó, isto é c = 1, n0 = 1). Como FatorAltura é O(n), ele é assintoticamente ótimo. Nenhum balanceamento baixa a classe: o gargalo é o tamanho da saída, não a estratégia.

Os quadros simultaneamente ativos formam um caminho da raiz até uma chamada vazia. Numa cadeia de n nós são n + 1 quadros; numa árvore balanceada de altura ⌊lg n⌋ são ⌊lg n⌋ + 2. Para n = 106 é a diferença entre 106 + 1 quadros (estouro certo na maioria dos ambientes) e ⌊lg 106⌋ + 2 = 21 quadros. Não é ganho de complexidade de tempo; é ganho de complexidade de espaço auxiliar, de Θ(n) para Θ(lg n). Responder “Θ(n) nos dois casos, logo tanto faz” seria errado por omissão.

Por que não é como a busca binária. É tentador esperar ganho logarítmico “porque a árvore está balanceada”. A busca binária tem T(n) = T(n/2) + Θ(1), ou seja α = 1, β = 2, k = 0, βk = 1; aqui α = βk, segundo caso, dando Θ(nk lg n) = Θ(lg n). A queda vem de α = 1: a busca binária descarta uma das metades. FatorAltura tem α = 2 — desce nas duas e não descarta nada, porque precisa do f.b. de todo mundo. É a eliminação, não a divisão equilibrada, que produz ganho assintótico.

6. Uma nota sobre a contagem escrita no slide

O resultado final do slide está exatamente certo: a expressão “(n+1)Θ(1) + nΘ(1)” corresponde termo a termo ao que foi provado — n + 1 chamadas com árvore vazia e n com árvore não vazia. Não é sequer aproximação: é o custo exato, e vale para qualquer forma, não só para a cadeia.

E o passo intermediário é abreviado, não errado — vale desfazer a objeção fácil. O slide escreve T(n) = T(1) + ∑i=2n Θ(1), e isso de fato liga os extremos: cada Θ(1) da soma é o incremento de um passo do desenrolar, que já embute o T(0) do filho vazio, de modo que

T(1) + (n−1)·(T(0) + b) = (2a + b) + (n−1)(a + b) = (n+1)a + n·b

que é exatamente o lado direito que o slide escreve. Objetar que “a soma tem n−1 parcelas e o total tem 2n+1” seria contar parcelas — e Θ(1) não se compromete com constante nenhuma. O que vale registrar é outra coisa: somar um número variável de termos Θ(1) só é legítimo porque existe uma constante uniforme limitando todos eles — max(a, b) —, e essa uniformidade não está na notação, está no algoritmo. E o caso base declarado é n = 0: parar em T(1) é atalho legítimo, desde que se saiba que T(1) = 2a + b, e não a.

E o slide diz “o pior caso da recorrência parece ser quando um de ne, nd é sempre zero”. O teorema da seção 3 mostra que, no modelo de contagem de operações, não há pior caso de forma: toda árvore com n nós custa exatamente o mesmo. A cadeia é o pior caso para outra grandeza — a profundidade da pilha. O “parece ser” do slide é prudente, e o exercício é justamente o convite a descobrir que a suspeita não se confirma no tempo.
