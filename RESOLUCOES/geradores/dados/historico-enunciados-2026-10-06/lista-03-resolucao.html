Estrutura das provas por indução. Cada item da Questão 4 segue o mesmo esqueleto: enunciar P(n); verificar a base no valor inicial que o enunciado exige, com os dois lados avaliados; escrever a hipótese indutiva; e provar o passo, marcando o ponto exato em que a hipótese é aplicada. Questão 1

Enunciado

Alice e Bob estão discutindo sobre o desempenho de seus algoritmos de ordenação. Alice afirma que o seu algoritmo de ordenação executando em tempo Θ(n·lg n) é melhor que o algoritmo de Bob que executa em tempo Θ(n²). Para decidir qual é o melhor algoritmo, implementaram e executaram ambos os algoritmos no mesmo ambiente (mesma arquitetura, mesmo sistema operacional, mesma linguagem de programação e mesmo compilador) em uma série de dados. Para espanto de Alice, descobriram que quando n < 100 o algoritmo Θ(n²) é mais rápido e apenas quando n ≥ 100 é que o algoritmo Θ(n·lg n) é melhor. Explique como essa situação pode ocorrer.

Não há contradição alguma. Alice está certa assintoticamente, e a medição também está certa na faixa testada. As duas coisas convivem porque Θ descarta exatamente aquilo que decide o desempenho para n pequeno.

1. O que Θ afirma — e o que não afirma

Por definição, T(n) = Θ(g(n)) significa que existem c1, c2 > 0 e n0 > 0 com 0 ≤ c1g(n) ≤ T(n) ≤ c2g(n) para todo n ≥ n0. Disso decorrem três coisas:

(i) as constantes c1, c2 são arbitrárias — nada limita seu tamanho; (ii) termos de menor ordem desaparecem, pois 5n lg n + 500n + 20000 também é Θ(n lg n); e (iii) a garantia só vale a partir de um n0, que pode ser grande.

Ou seja, "Θ(n lg n) é melhor que Θ(n²)" é afirmação sobre o limite, não sobre cada valor de n.

2. Um exemplo concreto que reproduz o cenário

Tome

TA(n) = 15·n·lg n + 20  (Alice)   e   TB(n) = n²  (Bob).

TA é Θ(n lg n) e TB é Θ(n²), exatamente como Alice e Bob anunciaram. A única diferença estrutural é a constante 15 e o termo constante 20 — precisamente o que Θ apaga. O 20 tem leitura natural: é o custo fixo de preparação, como alocar o vetor auxiliar de um mergesort.

O termo constante 20 não é decoração: sem ele, com TA(n) = 15n lg n, teríamos TA(1) = 15·1·lg 1 = 0, porque lg 1 = 0. Alice "venceria" em n = 1 com tempo zero — um artefato degenerado que contradiz o enunciado, já que ele afirma que Bob é mais rápido para todo n < 100. Com o termo constante, Bob vence em todos os inteiros de 1 a 99, sem furos.

3. O ponto de cruzamento, algebricamente

Ignorando o termo constante para achar a ordem de grandeza do cruzamento, resolve-se

15·n·lg n = n²  ⟺  15·lg n = n  ⟺  n / lg n = 15,

onde a divisão por lg n exige lg n > 0, isto é, n ≥ 2 — restrição que precisa ser declarada.

Seja φ(n) = n / lg n. Derivando, φ'(n) = ln 2·(ln n − 1)/(ln n)², que é positiva quando ln n > 1, ou seja n > e ≈ 2,718. Logo φ é estritamente crescente a partir de n = 3, e só nessa região a equação φ(n) = 15 tem solução única.

φ(99) = 14,93 < 15 < 15,05 = φ(100).

Esse bracket localiza a raiz da equação simplificada 15n·lg n = n², que é n ≈ 99,563. A raiz da equação completa 15n·lg n + 20 = n² é outra: n ≈ 99,819. O bracket correspondente é TA(99) = 9 864,6 > 9 801 = TB(99) e TA(100) = 9 985,8 < 10 000 = TB(100).

Resolvendo numericamente TA(n) = TB(n), o cruzamento cai em n ≈ 99,82 — entre 99 e 100. Portanto o primeiro inteiro em que Alice vence é n = 100, exatamente o limiar observado.

Por que não volta a inverter. Seja h(n) = TB(n) − TA(n) = n² − 15n·lg n − 20. Sua derivada é h′(n) = 2n − 15·lg n − 15/ln 2, que é negativa só para n ≤ 53 e positiva a partir de n = 54. Logo h é crescente em todo n ≥ 54 e, como h(99) < 0 < h(100), ela troca de sinal uma única vez. Assim Bob vence exatamente em 1 ≤ n ≤ 99, sem furos, e Alice de n = 100 em diante, sem reversão.

Cuidado com dois limiares diferentes. O número 100 é o ponto de cruzamento entre TA e TB, causado pela constante 15. Ele não é o n0 mínimo de nenhuma das duas declarações Θ — nelas basta n0 = 2 — e nada na definição de Θ o determina. (Rigorosamente, n0 não é único: qualquer valor maior também serve, inclusive 100. O que se quer dizer é que o cruzamento não é o menor n0 possível, e que ele vem da constante 15, não da definição.) Chamar o cruzamento de "n0 do par" confunde duas constantes que não têm relação: uma liga um algoritmo à sua própria classe, a outra compara dois algoritmos.

4. Outros fatores que contribuem

Termos de menor ordem. O custo real de Alice poderia ser 5n lg n + 500n + 3000, que continua sendo Θ(n lg n). Para n pequeno o 500n e a constante dominam; para n grande somem diante de 5n lg n.

Fatores que o modelo RAM não enxerga. O modelo cobra custo unitário por operação, mas na máquina real o algoritmo Θ(n²) pode ter localidade de referência muito melhor (varre vetores contíguos, que cabem em cache), pode ser iterativo — sem o custo de empilhar chamadas recursivas — e pode operar in place, sem alocar memória auxiliar nem pagar cópias. Todos esses custos entram na constante multiplicativa do algoritmo assintoticamente melhor.

É exatamente o caso do insertion sort (Θ(n²) no pior caso) contra o mergesort (Θ(n lg n)): para entradas pequenas o insertion sort é mais rápido na prática, e por isso implementações reais de mergesort e quicksort trocam para insertion sort quando o subproblema fica abaixo de um limiar de algumas dezenas de elementos.

5. Conclusão

A afirmação de Alice é sobre o comportamento quando n → ∞, e é verdadeira: a partir de n = 100 seu algoritmo é mais rápido, e a vantagem cresce sem limite, pois TB(n)/TA(n) ≈ n/(15 lg n) → ∞. A observação empírica apenas revela onde está o ponto de cruzamento desse par de implementações — e quem o determina são as constantes, que a notação Θ deliberadamente ignora.

Questão 2

Enunciado

Considere    f(n) = n  se n é ímpar;    f(n) = n²  se n é par.

Apresente um limite assintótico para a função f tão firme (restrito/justo) quanto possível, usando a notação Big O.

Resposta: f(n) = O(n²), com testemunhas c = 1 e n0 = 1.

n12345678910
f(n)143165367649100

(1) Limite superior: f(n) = O(n²)

Testemunhas c = 1 e n0 = 1, fixadas antes e independentes de n. Seja n ≥ 1:

Caso n par: f(n) = n² ≤ 1·n², com igualdade.
Caso n ímpar: f(n) = n. De 1 ≤ n, multiplicando pelo positivo n, vem n ≤ n². Logo f(n) ≤ 1·n².

Em ambos f(n) ≥ 0. Portanto 0 ≤ f(n) ≤ 1·n² para todo n ≥ 1. ∎

(2) Esse teto é o mais firme possível: f(n) não é O(n)

Nos índices pares a função vale exatamente n², então nenhuma função que cresça estritamente mais devagar pode servir de teto.

Suponha por absurdo f(n) = O(n): existem c > 0 e n0 com f(n) ≤ c·n para n ≥ n0. Escolha um n par com n > máx(n0, c) — existe, pois há infinitos pares. Aí f(n) = n², e a desigualdade daria n² ≤ c·n; dividindo por n > 0, n ≤ c, contradizendo n > c. ∎

O mesmo argumento vale para qualquer g com g(n) = o(n²). Logo n² é o teto justo.

(3) Ponto central: f(n) não é Θ(n²)

Θ exige teto e piso da mesma ordem. O teto vale, mas o piso não — e é isso que a questão testa.

Suponha por absurdo f(n) = Ω(n²): existem c > 0 e n0 com c·n² ≤ f(n) para n ≥ n0. Escolha um n ímpar com n > máx(n0, 1/c). Aí f(n) = n, e a desigualdade daria c·n² ≤ n; dividindo por n > 0, c·n ≤ 1, isto é n ≤ 1/c — contradizendo n > 1/c. ∎

Note que a constante c não salva a situação por menor que seja: ela apenas afasta o primeiro ponto de falha, sem eliminá-lo. Para c = 1 a desigualdade falha já em n = 3; para c = 0,01 falha a partir de n = 101; para c = 0,0001, a partir de n = 10 001. Sempre restam infinitos ímpares onde falha.

Como f(n) ≥ n para todo n ≥ 1, vale f(n) = Ω(n). Assim n ≤ f(n) ≤ n²: a função fica espremida entre as duas ordens sem ser Θ de nenhuma das duas, porque oscila entre elas conforme a paridade.

Questão 3

Enunciado

Têm-se 2n moedas de ouro, sendo uma delas falsa, com peso menor do que as demais. Dispõe-se de uma balança de dois pratos, sem nenhum peso. Vamos mostrar, por indução sobre n, que é possível achar a moeda falsa com n pesagens.

Bissecção: divide-se em duas metades, pesa-se uma contra a outra, e a metade mais leve é um problema do mesmo tipo com a metade das moedas. A indução formaliza isso — e o ponto delicado é enunciar P(n) para qualquer conjunto de moedas, porque a hipótese será aplicada a um subconjunto.

1. Suposições e a proposição

Suposições declaradas. (1) Todas as moedas verdadeiras têm o mesmo peso p; a falsa tem peso q < p. (“As demais” são as verdadeiras; o enunciado diz que a falsa pesa menos que elas.) (2) Uma pesagem põe um conjunto de moedas em cada prato e observa um de três resultados: prato esquerdo mais pesado, prato direito mais pesado, ou equilíbrio. (3) “Com n pesagens” é lido como “com no máximo n pesagens”; o procedimento abaixo usa exatamente n. (4) n é inteiro, n ≥ 1 (se 0 ∈ ℕ, o caso n = 0 também vale e é tratado à parte).

Proposição. P(n): para todo conjunto M de 2n moedas no qual exatamente uma é falsa, de peso q, e as demais têm todas o mesmo peso p > q, é possível identificar a moeda falsa de M usando n pesagens.

A quantificação “para todo conjunto M” é essencial: no passo, a hipótese de indução será aplicada a um subconjunto das moedas originais, não ao conjunto original.

2. A indução

Base (n = 1). M tem 21 = 2 moedas. Põe-se uma em cada prato (1 pesagem). Um prato tem peso q e o outro, p; como q < p, a balança não equilibra, e a moeda do prato mais leve é a falsa. P(1) vale, com 1 pesagem. (Caso n = 0, se 0 ∈ ℕ: M tem 20 = 1 moeda, que é a falsa; 0 pesagens. P(0) vale.)

Hipótese de indução. Seja n ≥ 1 fixado e suponha P(n): em qualquer conjunto de 2n moedas com exatamente uma falsa, mais leve, e as demais de mesmo peso, acha-se a falsa com n pesagens.

Passo. Seja M um conjunto qualquer de 2n+1 moedas com exatamente uma falsa (peso q) e as demais de peso p > q. Como 2n+1 = 2·2n, divide-se M em dois conjuntos disjuntos M1 e M2 com 2n moedas cada, e põe-se um em cada prato (1 pesagem). A falsa está em exatamente um dos dois; chame-o de Mi e o outro de Mj. Então

peso(Mi) = (2n − 1)·p + q    e    peso(Mj) = 2n·p,    logo   peso(Mj) − peso(Mi) = p − q > 0.

A balança não equilibra e o prato mais leve é o de Mi: a pesagem revela qual grupo contém a falsa. Mi é um conjunto de 2n moedas com exatamente uma falsa, de peso q, e as demais de peso p > q — exatamente a situação de P(n). Pela hipótese de indução, aplicada ao conjunto Mi, a falsa de Mi (que é a falsa de M) é identificada com n pesagens. Total: 1 + n = n + 1 pesagens. Logo P(n+1).

Conclusão. Pelo princípio da indução (base P(1), passo P(n) → P(n+1) para todo n ≥ 1), P(n) vale para todo n ≥ 1: com 2n moedas, acha-se a falsa com n pesagens. ∎ (Se 0 ∈ ℕ, a base P(0) com o mesmo passo, aplicado também em n = 0 — divide 2 moedas em grupos de 1, pesa, e P(0) identifica a falsa no grupo mais leve —, dá o resultado para todo n ≥ 0.)

Fencepost. Passo com n = 1 (o menor em que é aplicado, na leitura n ≥ 1): 4 moedas → dois grupos de 2 → 1 pesagem → grupo mais leve de 2 moedas → base: 1 pesagem. Total 2 = n + 1. O número de pesagens satisfaz W(1) = 1, W(n+1) = W(n) + 1, logo W(n) = n = lg(2n), o logaritmo do número de moedas.

3. Observações

Neste procedimento o resultado “equilíbrio” nunca ocorre: os dois pratos têm o mesmo número de moedas e só um contém a falsa.

n pesagens bastam, mas não são o mínimo para n ≥ 3. Cada pesagem tem 3 resultados possíveis, e há 2n possibilidades para a posição da falsa; logo qualquer estratégia precisa de pelo menos ⌈log3 2n⌉ pesagens, e dividir em três grupos aproveita o resultado “equilíbrio”. Exemplo: 8 moedas (n = 3) em 2 pesagens — pesa-se 3 contra 3; se equilibrar, a falsa está entre as 2 restantes, e pesa-se uma contra a outra; se não, está entre as 3 do prato mais leve, e pesa-se uma contra outra dessas três: o prato mais leve indica a falsa e, no equilíbrio, a falsa é a terceira. Para todo n ≥ 3 isso dá uma estratégia com menos de n pesagens: faz-se a bissecção por n − 3 pesagens, até restar um grupo de 23 = 8 moedas que contém a falsa, e resolve-se esse grupo em 2 pesagens como acima; total (n − 3) + 2 = n − 1 < n. O enunciado pede apenas que n pesagens sejam suficientes, que é o que a indução mostra.

Questão 4

Enunciado

Prove as assertivas abaixo usando o método da indução matemática.

  1. P(n) : n! > 2n , ∀ n ≥ 4
  2. P(n) : 2 + 4 + 6 + … + 2n = n² + n , ∀ n ≥ 1
  3. P(n) : 1 + 2 + 3 + … + n = n(n+1)/2 , ∀ n ≥ 1
  4. T(n) = 1 se n = 1;   T(n) = T(n−1) + n se n ≥ 2.    A fórmula fechada é T(n) = n(n+1)/2
  5. T(n) = 1 se n = 1;   T(n) = 2·T(n−1) + 1 se n ≥ 2.    A fórmula fechada é T(n) = 2n − 1

(a) n! > 2n, para todo n ≥ 4

P(n): n! > 2n.

Base (n = 4). 4! = 24 e 24 = 16. Como 24 > 16, P(4) é verdadeira.

Hipótese indutiva. Suponha n! > 2n para algum n ≥ 4.

Passo. Queremos (n+1)! > 2n+1. Da definição de fatorial,

(n+1)! = (n+1)·n! > (n+1)·2n   ← aqui a hipótese é aplicada

Como n ≥ 4, tem-se n + 1 ≥ 5 > 2, logo

(n+1)·2n > 2·2n = 2n+1.

Encadeando, (n+1)! > 2n+1, isto é, P(n+1). ∎

A base em 4 é justa, não folgada. A afirmação é falsa antes disso: 1! = 1 > 2 é falso; 2! = 2 > 4 é falso; 3! = 6 > 8 é falso. Só em n = 4 ela passa a valer. Começar a base em n = 1 não seria apenas erro de forma — seria "provar" algo falso. E note que a restrição n ≥ 4 é usada exatamente uma vez no passo: para garantir n + 1 > 2.

(b) 2 + 4 + 6 + … + 2n = n² + n, para todo n ≥ 1

P(n): Σi=1..n 2i = n² + n.

Base (n = 1). Esquerda: 2·1 = 2. Direita: 1² + 1 = 2. Iguais.

Hipótese indutiva. Suponha 2 + 4 + … + 2n = n² + n para algum n ≥ 1.

Passo. A soma até 2(n+1) é

(2 + 4 + … + 2n) + 2(n+1) = (n² + n) + 2n + 2   ← hipótese aplicada

= n² + 3n + 2.

E a fórmula avaliada em n+1 dá

(n+1)² + (n+1) = n² + 2n + 1 + n + 1 = n² + 3n + 2.

As duas expressões coincidem, logo P(n+1). ∎

(c) 1 + 2 + 3 + … + n = n(n+1)/2, para todo n ≥ 1

P(n): Σi=1..n i = n(n+1)/2.

Base (n = 1). Esquerda: 1. Direita: 1·2/2 = 1. Iguais.

Hipótese indutiva. Suponha 1 + 2 + … + n = n(n+1)/2 para algum n ≥ 1.

Passo.

(1 + 2 + … + n) + (n+1) = n(n+1)/2 + (n+1)   ← hipótese aplicada

Fatorando (n+1):

= (n+1)·(n/2 + 1) = (n+1)·(n+2)/2,

que é a fórmula avaliada em n+1. ∎

(d) T(n) = T(n−1) + n, T(1) = 1  ⟹  T(n) = n(n+1)/2

P(n): T(n) = n(n+1)/2.

Base (n = 1). Pela definição, T(1) = 1. Pela fórmula, 1·(1+1)/2 = 1. Iguais.

Hipótese indutiva. Suponha T(n−1) = (n−1)·n/2 para algum n ≥ 2.

Passo. Como n ≥ 2, vale o caso recursivo da definição — e é dele que se parte:

T(n) = T(n−1) + n = (n−1)·n/2 + n   ← hipótese aplicada

= (n² − n)/2 + 2n/2 = (n² + n)/2 = n(n+1)/2. ∎

Primeiros valores pela recorrência: 1, 3, 6, 10, 15, 21, 28, 36 — que coincidem com n(n+1)/2.

(e) T(n) = 2·T(n−1) + 1, T(1) = 1  ⟹  T(n) = 2n − 1

P(n): T(n) = 2n − 1.

Base (n = 1). Pela definição, T(1) = 1. Pela fórmula, 21 − 1 = 1. Iguais.

Hipótese indutiva. Suponha T(n−1) = 2n−1 − 1 para algum n ≥ 2.

Passo. Como n ≥ 2, parte-se do caso recursivo da definição:

T(n) = 2·T(n−1) + 1 = 2·(2n−1 − 1) + 1   ← hipótese aplicada

= 2n − 2 + 1 = 2n − 1. ∎

O fecho da conta é o −2 + 1 = −1: é ali que a fórmula se encaixa, e é o passo que não se deve pular. Primeiros valores pela recorrência: 1, 3, 7, 15, 31, 63, 127, 255 — que coincidem com 2n − 1.

Sobre a estrutura dos itens (d) e (e). Nos dois, o passo começa aplicando a definição recursiva e termina na fórmula fechada. O caminho inverso — escrever a fórmula em n e manipulá-la até chegar em algo verdadeiro — é circular: usaria a tese para provar a tese. A distinção é sutil na leitura e decisiva na correção.

Questão 5

Enunciado

Seja a sentença aberta em ℕ:

P(n) :   1 + 2 + ··· + n = n(n + 1)/2 + 1,

mostre que:
(i) Qualquer que seja n ∈ ℕ, se P(n) é verdadeira, então P(n + 1) é verdadeira.
(ii) P(n) não é verdadeira para nenhum valor de n ∈ ℕ.

O passo vale, a base não — e sem base a indução não conclui nada. Seja S(n) = 1 + 2 + ··· + n = Σk=1..n k. O enunciado não diz se 0 ∈ ℕ; a solução cobre as duas convenções. Para n = 0, S(0) é a soma vazia, igual a 0. Assim, P(n) é a afirmação S(n) = n(n+1)/2 + 1.

(i) Para todo n ∈ ℕ, P(n) → P(n+1)

Seja n ∈ ℕ arbitrário e suponha P(n), isto é, S(n) = n(n+1)/2 + 1. Como S(n+1) = S(n) + (n+1) (separação do último termo; vale também para n = 0, pois S(1) = 0 + 1),

S(n+1) = S(n) + (n+1) = n(n+1)/2 + 1 + (n+1)   ← hipótese P(n)

= [n(n+1) + 2(n+1)]/2 + 1 = (n+1)(n+2)/2 + 1.

Como (n+1)((n+1)+1)/2 = (n+1)(n+2)/2, isto é exatamente P(n+1). Como n foi arbitrário, a implicação vale para todo n ∈ ℕ. ∎

A prova de (i) é direta e usa apenas a hipótese P(n) e a definição de S; não usa (ii) nem a fórmula verdadeira de S(n).

(ii) P(n) é falsa para todo n ∈ ℕ

Lema. Para todo n ∈ ℕ, S(n) = n(n+1)/2.

Base. S(1) = 1 = 1·2/2; e, se 0 ∈ ℕ, S(0) = 0 = 0·1/2.

Hipótese. Para um n ∈ ℕ fixado, S(n) = n(n+1)/2.

Passo. S(n+1) = S(n) + (n+1) = n(n+1)/2 + (n+1) = (n+1)(n+2)/2  ← hipótese aplicada. Logo o Lema vale para todo n ∈ ℕ. ∎

(É a mesma identidade da Questão 4(c) desta lista, aqui estendida a n = 0.)

Conclusão de (ii). Para qualquer n ∈ ℕ, pelo Lema, o lado esquerdo de P(n) vale S(n) = n(n+1)/2, e o lado direito vale n(n+1)/2 + 1 = S(n) + 1. Como S(n) ≠ S(n) + 1, P(n) é falsa. Como n foi arbitrário, P(n) não é verdadeira para nenhum n ∈ ℕ. ∎

Por que (ii) não se prova só olhando a base. Verificar que P(1) é falsa (1 ≠ 2) mostra que a base falha, mas não mostra que P(n) é falsa para todo n: uma propriedade pode falhar nos primeiros valores e valer depois (por exemplo, n! > 2n é falsa em n = 1, 2, 3 e verdadeira para todo n ≥ 4 — Questão 4(a) desta lista). Por isso (ii) precisa de um argumento que valha para todo n, e não só da base. Aqui esse argumento é o Lema, que mostra que os dois lados diferem por exatamente 1 em todo n. Não é o único caminho: a conta de (i) é reversível — como S(n+1) = S(n) + (n+1) e (n+1)(n+2)/2 + 1 = [n(n+1)/2 + 1] + (n+1), vale S(n+1) = (n+1)(n+2)/2 + 1 se e somente se S(n) = n(n+1)/2 + 1 —, logo P(n+1) → P(n), isto é, ¬P(n) → ¬P(n+1); uma indução sobre ¬P, com base ¬P(1) (ou ¬P(0)), também prova (ii). Nos dois caminhos há base e passo: a falha da base, sozinha, não basta.

O que a questão ensina

(i) e (ii) juntos mostram que o passo indutivo sozinho não prova nada: aqui P(n) → P(n+1) vale para todo n e, mesmo assim, P(n) é falsa para todo n. O que falta é um ponto de partida: P(1) (ou P(0)) é falsa e, por (ii), nenhum P(m) é verdadeiro, de modo que a cadeia de implicações nunca é disparada, qualquer que seja o valor inicial escolhido. A questão mostra que a base é indispensável: um passo válido, sozinho, não prova nada.
